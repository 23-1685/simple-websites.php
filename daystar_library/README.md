# Daystar University Library Management System

## Setup
1. Import the SQL script into phpMyAdmin.
2. Place all files in htdocs/daystar_library.
3. Open http://localhost/daystar_library/index.php

## Features
- Manage books, students, and loans.
- Issue and return books with fine calculation.
- Responsive design.

## Requirements
- XAMPP with PHP 7.4+ and MySQL.
